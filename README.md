# Replication Archive: Birds of a Bounded Feather

This repository contains the replication package for our paper: **"Birds of a Bounded Feather: Religious Homophily, Opportunity Structure, and Friendship Formation in a Highly Homogeneous Cohort"** (NetHealth Religion Project).

The analytical pipeline — data cleaning, model fitting, plot generation, and manuscript compilation — runs as a sequence of modular R scripts in `Code/`.

---

## 1. Directory Structure

```
├── README.md               # This replication guide
├── AGENTS.md                # Project memory log: data schema, methods, and decision history
├── paper.tex                # LaTeX manuscript file
├── references.bib           # Bibliography file
├── Data/                    # Raw and derived data (BasicSurvey, NetWorkSurvey CSVs)
├── Plots/                   # Figures included in the manuscript (fig-*.png)
├── Tabs/                    # LaTeX tables \include-d by paper.tex (tbl-*.tex)
├── Code/                    # Modular R scripts implementing the analysis pipeline (see below)
└── Archive/                 # Superseded/orphaned scripts and outputs, kept for reference only
```

`Archive/` holds material not used to produce the current manuscript: an earlier Quarto-based
pipeline attempt (`analysis.qmd`/`analysis.html`), regression/figure outputs superseded by later
script revisions, and standalone HTML supplementary tables generated by
`Code/06_save_tables_html.R`. Nothing in `Archive/` is read by `paper.tex` or by any script in
`Code/`.

## 4. Running the Pipeline

Run the scripts in `Code/` in order:

1. `Code/prep_data20240603.R` — legacy cleaning script producing the analysis-ready data frames.
2. `Code/01_longitudinal_descriptives.R` — group-level Yule's Q across all 8 waves.
3. `Code/02_dyadic_models.R` — Wave 3 nested dyadic logistic regressions with opportunity offset;
   prints group-level ego/tie sample sizes (matches `Tabs/tbl-wave3-reg.tex`).
4. `Code/02_dyadic_models_pooled.R` — pooled Waves 3–8 dyadic logistic regressions with clustered
   SEs; prints group-level ego/tie sample sizes (matches `Tabs/tbl-pooled-interaction-reg.tex`).
5. `Code/02_dyadic_models_interaction.R` — Time × Religion and Intimacy × Religion interaction
   models.
6. `Code/04_plot_opportunity_stability.R`, `Code/05_plot_active_coefficients.R` — figure generation
   into `Plots/`.
7. `Code/07_yules_q_permutation_test.R` — degree-preserving permutation null test for Yule's Q;
   writes `Data/yules_q_permutation_null.csv` and `Tabs/tbl-yules-q-null.tex`.

`Code/06_save_tables_html.R` generates standalone HTML supplementary tables (archived copies live
in `Archive/supplementary_html_tables/`); it is **not** the source of the `.tex` tables included in
`paper.tex` and can drift out of sync with them — regenerate before relying on it.

### Compile the Manuscript

```bash
latexmk -pdf paper.tex
```

*Outputs:* `paper.pdf`, the manuscript with all figures and tables as submitted.

## 5. Methodological Notes

- **The Group-Size Artifact:** Group-level, baseline-adjusted Yule's Q establishes that each
  religious group individually exceeds its own chance-mixing baseline. Its *magnitude* is **not**
  comparable across groups of very different sizes — confirmed by simulation (see AGENTS.md §3.A).
- **Opportunity Offset:** Dyadic tie-level logistic regressions include a mathematical opportunity
  offset ($\log(p/(1-p))$) that corrects point-estimate bias from unequal baseline group
  proportions. It does **not** equalize estimation precision across groups of very different
  sizes — bootstrap analysis shows the minority-group ranking (Other Religion vs. Protestant vs.
  No Religion) is not statistically distinguishable (see AGENTS.md §3.B).
- **Marginal Effects:** Interaction terms (Time × Religion, Intimacy × Religion) are evaluated on
  the probability scale via the `marginaleffects` package to avoid non-linear logit-scaling
  artifacts.
- **Mediation:** The `mediation` package is used to test (and reject) structural foci as mediators
  of secular ("No Religion") homophily.

See `AGENTS.md` for the full methodological history, known limitations, and open items.
