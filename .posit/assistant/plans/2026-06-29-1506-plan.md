# Plan: Split NetHealth Religion Project into Analysis (.qmd) and Manuscript (.tex)

## Objective
Restructure the project to separate computation from writing. We will create a reproducible Quarto document (`analysis.qmd`) that handles all data processing, modeling, and output generation (tables and plots), and a formal LaTeX manuscript (`paper.tex`) structured for journal submission that imports these outputs.

## Step 1: Create the Reproducible Analysis Quarto Document (`analysis.qmd`)
1.  **Extract Code from `NetHealth_Religion_Paper.qmd`:**
    *   Initialize a new Quarto file (`analysis.qmd`) dedicated solely to computation.
    *   Migrate the setup, data cleaning, and imputation pipeline.
    *   Migrate all statistical modeling (Yule's Q, Wave 3 cross-sectional GLMs, pooled longitudinal models with clustered SEs, interaction models, and ERGMs).
2.  **Redirect Outputs to Disk:**
    *   Modify plot generation code to use `ggsave()` to save plots as PDF/PNG files into the `Plots/` directory (e.g., `Plots/fig-yules-q.pdf`, `Plots/fig-opportunity-stability.pdf`, `Plots/fig-active-coefs.pdf`).
    *   Modify table generation code. Currently, tables use `kable` for HTML/markdown. We will update the code to generate raw LaTeX tables (using `kableExtra`, `stargazer`, or `modelsummary`) and save them to the `Tabs/` directory as `.tex` files (e.g., `Tabs/tab-wave3-reg.tex`).
3.  **Incorporate Methodological Notes:**
    *   Keep the technical justifications (e.g., dyadic GLM vs. MLM, opportunity offset math) from the Methodological Report as markdown text between code chunks to serve as a reproducible lab notebook.

## Step 2: Create the Journal-Ready LaTeX Manuscript (`paper.tex`)
1.  **Extract Prose and Theory:**
    *   Create a new LaTeX file (`paper.tex`).
    *   Set up a professional preamble (`\documentclass{article}`, `\usepackage{graphicx}`, `\usepackage{booktabs}`, `\usepackage{natbib}`, `\usepackage{amsmath}`).
    *   Migrate the Introduction, Theory (Minority Distinctiveness Theory vs. Majority Exclusiveness Theory), Methods, Results, Discussion, and Conclusion sections from `NetHealth_Religion_Paper.qmd` into proper LaTeX sections (`\section{}`, `\subsection{}`).
2.  **Link Outputs:**
    *   Insert `\includegraphics{Plots/...}` commands to pull in the generated figures.
    *   Insert `\input{Tabs/...}` commands to pull in the generated regression tables.
3.  **Format Technical Appendices:**
    *   Migrate the mathematical defenses (Opportunity Offset, Clustered SEs) into LaTeX appendices.

## Step 3: Cleanup and Verification
1.  Ensure all paths use relative structures (e.g., `Plots/` and `Tabs/`).
2.  Verify the `paper.tex` file compiles successfully (if required).
3.  (Optional) Archive the old `NetHealth_Religion_Paper.qmd` and `NetHealth_Religion_Methodological_Report` files to an archive directory to avoid confusion.

## Summary of Deliverables
1.  `analysis.qmd`: Executable R code that writes assets to `Plots/` and `Tabs/`.
2.  `paper.tex`: The prose manuscript that reads from `Plots/` and `Tabs/`.
