## 1. Project

The project studies religious homophily in friendship formation among NetHealth students at the University of Notre Dame (N = 722 egos, Waves 1–8). It tests the Minority Distinctiveness Hypothesis (MDH) against the Majority Exclusiveness Hypothesis (MEH) using tie-level logistic regressions with an opportunity offset, supplemented by group-level Yule's Q trajectories.

Reviewer objections and how the project responds:
- **Group-size artifact:** the E-I index was replaced by baseline-adjusted Yule's Q, and dyadic models carry an opportunity offset. The offset corrects *bias* in point estimates. It does **not** equalize *precision* across group sizes; the permutation test and bootstrap address precision.
- **Foci and alternative homophilies:** dorm co-residence, roommates, gender, race, closeness, and religious salience are controls.
- **Activity/popularity confound (Reviewer 1):** ego log out-degree and alter log in-degree (computed from the full wave roster) are added. They do not meaningfully attenuate the group coefficients.
- **ERGMs:** infeasible. Only about 32% of `alterid` values resolve to surveyed egos, so there is no closed sociomatrix.
- **Mediation:** not pursued. The Wave 3 total effect is null, so there is nothing to decompose.

Current manuscript conclusion: non-Catholic groups collectively show opportunity-adjusted in-group tie excess relative to the Catholic majority. A finer ranking among Protestant, No Religion, and Other Religion students is not statistically reliable.

## 2. Data and Samples

**Files in `Data/`:**
- `BasicSurvey.csv`: ego-level survey, key `egoid`. Used: `yourelig_1` (religion), `gender_1` (coded Female/Male), `race_1`, `discussrelig_2` (salience, Wave 2).
- `NetWorkSurvey.csv`: nominations (`egoid` → `alterid`, `wave`). Used: `altrelucat`, `family`, `altrelig`, `altsex`, `altwhite`/`altblack`/`altasian`/`althisla`, `roommates`, `samedorm`, `close`.

**Sample flow** (verified by `Code/00_sample_descriptives.R`):
- 722 egos; 4 with missing religion.
- 35,912 nominations (all waves). 17,452 are to student alters (48.6%). 312 on-campus family nominations are removed, leaving **17,140 analytic student ties** (all waves). 14,364 of these have alter religion reported.
- Regression sample, Waves 3–8, fully adjusted (Table 1 Models 1–3 and interaction): **428 egos / 9,522 ties**. By group: Catholic 326/7,393; No Religion 37/670; Other Religion 19/348; Protestant 46/1,111.
- Baseline bootstrap sample (Table 3 Panels A–B): **472 egos / 10,046 ties**, with no covariate filtering. Egos by group: Catholic 348; No Religion 52; Other Religion 22; Protestant 50.

**Family-tie exclusion** (`family == FALSE` after `altrelucat == "Student"`) is applied in every script that builds the analytic tie sample. Siblings who both attend the university would otherwise be counted as friends.

**Variables** (regression scripts):
- Outcome `same_religion`; offset `opportunity_offset = log(p/(1-p))`, with `p` the wave-specific share of the ego's group among analytic alters.
- `same_gender`; `same_race` (NA for Foreign Student and Other-race egos); `roommates`; `samedorm`.
- `close_num`: ordinal 1–4 via `case_when` (Distant, LessThanClose, MerelyClose, EspeciallyClose).
- `discuss_num`: 1–5 from `discussrelig_2`.
- `log_ego_degree` = log(out-degree in that wave's full roster); `log_alter_pop` = log1p(in-degree in that wave's full roster).
- `wave_num` = wave − 3 (interaction model only).

**Known label issue:** the manuscript text says "Woman/Man," but the data codes are "Female/Male."

## 3. Statistical Specification

- **Dyadic logit:** `glm(..., family = binomial, offset = ...)` with ego-clustered SEs (`sandwich::vcovCL`, cluster = `egoid`).
  - Table 1 Model 1: `ego_rel` only.
  - Model 2: + `same_gender`, `same_race`, `roommates`, `samedorm`, `close_num`, `discuss_num`.
  - Model 3: + `log_ego_degree`, `log_alter_pop`.
  - Interaction: Model 3 structure with `ego_rel * wave_num`.
- **No ego-level race/gender fixed effects** appear in any canonical model. Adding them would require changing the tables and prose.
- **Yule's Q** (Code 01): group-level, margin-free. Used descriptively, to establish that each group exceeds its own chance baseline. Magnitudes are not comparable across group sizes (simulation). Do not rank groups by Q.
- **Permutation test** (Code 07): 1,000 permutations per wave, `set.seed(6142)`. Holds each ego's degree and own religion fixed; redraws alter religion from that wave's observed pool.
- **Bootstrap** (Code 10): ego-level cluster bootstrap, 2,000 replicates, `set.seed(6284)`. Resamples egos with replacement within each religious group. Statistic = observed same-religion rate minus the mean opportunity baseline. Pairwise CIs come from independent group bootstraps.
- **Wald tests** (Code 10): manual contrasts `L'b`, variance `L'V L` with the ego-clustered vcov, χ² with 1 df. Holm correction across all six contrasts. The Catholic-vs-X contrasts are sanity checks. `car::linearHypothesis()` fails on level names with spaces, so manual contrasts are used.
- **Figure 3** (Code 05): a separate cross-sectional logit per wave with the Model 2 covariates *except* salience. Average marginal effect of each non-Catholic group vs. Catholic, averaged over all observed ties in the wave, with `opportunity_offset = 0` (equal-opportunity counterfactual, each group at 50%).
- **Interpreting absence of change:** group×wave interaction terms are not significant, but the non-Catholic groups have few unique egos. Describe this as absence of evidence for change, not evidence of stability.

## 8. Pitfalls

- **Ordinal coding:** `close_num` must use `case_when` (Distant 1, LessThanClose 2, MerelyClose 3, EspeciallyClose 4). Using `as.numeric(as.factor(close))` alphabetizes the categories and produces wrong coefficients. Do not reintroduce it.
- **Stale artifacts:** a `.tex` table and the script that claims to produce it can silently diverge. Confirm every quoted number against a fresh run before trusting it.
- **Text versus table:** check every significance claim against the table it cites.
- **Global environment:** nested `source()` without `local = TRUE` writes into the global environment. Keep the `local = TRUE` setting in `02b` and `10`.
- **`marginaleffects`:** `newdata` should contain only the model variables. A full 3,000-column data frame triggers a warning and slows the computation. Use `offset()` in the formula so predictions take the offset from `newdata`.
- **Editing in batches:** do not `sed -i` a file in the same batch as a pending edit to that file. The edit tool then reports stale state or fails. Re-grep after editing.
- **Overleaf:** fetch and diff before every push. Co-authors edit prose mid-session, so a fast-forward push cannot be assumed.
- **Mediation:** do not reintroduce an ACME decomposition of an already-null total effect.
